# Development reference

Stratum is a Horizon-based Android client. Public project information belongs in
[README.md](../README.md), [Android development](android-bootstrap.md),
[integration provenance](android-provenance.md) and [source policy](source-policy.md).

Personal session notes, device identifiers, network addresses, screenshots and
local test logs must remain under ignored `.local/` paths. They must not be copied
into public documentation or commit messages.
